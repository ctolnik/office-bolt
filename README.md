# Office-Monitor - Панель управления

Веб-интерфейс администратора для системы мониторинга активности сотрудников Office-Monitor.

## 🚀 Технологии

- **React 18** с TypeScript (strict mode)
- **Vite** - быстрая сборка и разработка
- **shadcn/ui** - современные UI компоненты
- **Tailwind CSS** - утилитарный CSS фреймворк
- **TanStack Query** - управление серверным состоянием
- **TanStack Table** - мощные таблицы данных
- **Recharts** - графики и визуализация
- **React Hook Form** + **Zod** - формы и валидация
- **Axios** - HTTP клиент
- **React Router v6** - маршрутизация

## 📋 Возможности

### ✅ Реализовано (Phase 1)

- **Панель управления**
  - Статистические карточки (сотрудники, алерты, продуктивность, события)
  - Виджет активных агентов с автообновлением
  - Виджет последних алертов
  - График продуктивности за 7 дней

- **Управление агентами**
  - Список всех агентов с фильтрацией по статусу
  - Конфигурация мониторинга (интервалы скриншотов, включение модулей)
  - Удаление агентов
  - Автообновление каждые 30 секунд

- **Управление сотрудниками**
  - CRUD операции (создание, редактирование, удаление)
  - Отслеживание согласия на мониторинг
  - Фильтрация и поиск
  - Быстрый переход к отчетам

- **Алерты**
  - Список всех алертов с фильтрацией
  - Цветовая кодировка по серьезности
  - Счетчик неразрешенных алертов

- **Система дизайна**
  - Профессиональная цветовая палитра
  - Адаптивный дизайн
  - Темная боковая панель с навигацией
  - Semantic tokens для всех цветов

### 🔄 В разработке (Phase 2-3)

- Детальные отчеты по активности
- Просмотр скриншотов
- Форматированный просмотр клавиатурных событий
- USB события и связанные файловые операции
- DLP алерты с визуальным выделением
- Экспорт в PDF/Excel
- Настройки системы

## 🛠️ Установка и запуск

```bash
# Клонирование репозитория
git clone <repository-url>
cd frontend

# Установка зависимостей
npm install

# Создание .env файла (скопируйте из .env.example)
cp .env.example .env

# Запуск в режиме разработки
npm run dev

# Сборка для production
npm run build

# Предпросмотр production сборки
npm run preview
```

## ⚙️ Конфигурация

Создайте файл `.env` на основе `.env.example`:

```env
# Backend API URL
VITE_API_URL=http://localhost:8080

# Feature flags
VITE_ENABLE_SCREENSHOTS=true
VITE_ENABLE_KEYLOGGER=true
VITE_ENABLE_DLP=true

# Auto-refresh intervals (milliseconds)
VITE_AGENTS_REFRESH_INTERVAL=30000
VITE_DASHBOARD_REFRESH_INTERVAL=60000

# API Security
VITE_API_KEY=your-api-key-here
```

## 🎨 Дизайн-система

Все цвета определены через CSS переменные в `src/index.css`:

- **Статусы**: online (зеленый), offline (красный), idle (желтый)
- **Серьезность**: critical, high, medium, low
- **Категории**: productive, unproductive, neutral, communication, system

## 🔒 Безопасность

- API ключ передается в заголовке `X-API-Key`
- Санитизация клавиатурных событий через DOMPurify
- Валидация всех форм через Zod
- Защита от XSS атак

## 📡 API интеграция

Базовый URL API: `http://localhost:8080/api`

Все запросы автоматически включают:
- Заголовок `X-API-Key` для аутентификации
- Обработку ошибок
- Таймаут 30 секунд

## 🚢 Деплой

```bash
# Сборка Docker образа
docker build -t office-monitor-frontend .

# Запуск контейнера
docker run -p 80:80 office-monitor-frontend
```

Приложение будет доступно на `http://localhost`

## 📝 Заметки разработчика

- **Язык UI**: Весь пользовательский интерфейс на русском языке
- **Язык кода**: Весь код (переменные, функции, комментарии) на английском
- **TypeScript**: Используется strict mode
- **Автообновление**: Dashboard обновляется каждые 60 сек, агенты каждые 30 сек
- **Состояние**: TanStack Query для серверного состояния, локальный state для UI
